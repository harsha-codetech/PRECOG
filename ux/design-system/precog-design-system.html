PRECOG
Design system · v0.2

Measure the person, not the minutes.

An instrument for behavioural deviation. It reports how a session compares to one person's own normal — and shows, in the drawing itself, how confident it is entitled to be.

01 — Palette

Cool drafting paper rather than warm cream, and a single confident ink blue doing the work of an accent. The status colours are deep and desaturated so that red stays meaningful instead of decorative. Every token has a counterpart in the opposite theme.

02 — Typography

Two families, split by job. Instrument Sans carries every word; Spline Sans Mono carries every number. Figures are tabular throughout, so a value that updates live never nudges the layout beside it.

03 — Signature · the tolerance band

One component carries the product. The band is this person's normal range, drawn as a dimensioned tolerance; the marker is the current session. Borrowing drafting's own convention, a solid edge is a defined limit and a dashed edge is an approximate one — so a baseline the system is unsure about is drawn as an engineer would draw it, not annotated with a percentage.

Defined tolerance

Narrow, solid edges. The system knows this person.

Outside tolerance

Distance from the corridor is the whole message.

Approximate tolerance

Dashed, because the limit is approximate. Widening is more honest than guessing.

04 — Screen states

Four states, and the fourth is the one this project earned the hard way: roughly a quarter of people have no stable scroll signature, so the interface has to be able to say so without sounding broken.

06 — Rules
evidence-requiredNo deviation is shown without the features that produced it. A bare score is a defect.
confidence-is-drawnUncertainty widens the band and dashes its edges. Never a percentage.
silence-while-learningNothing is flagged before the range holds. No comparison to other people, ever.
red-is-rarePronounced is reserved for sustained, severe deviation. Unusual does the ordinary work.
own-unitsEvery comparison is to this person's own history — never an average or a recommended limit.
dismissibleAny intervention can be dismissed without penalty. Repeated dismissal reduces frequency.
